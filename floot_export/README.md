# Floot Algo Trading Terminal export

Current Floot project: Algo trading1.

This folder is the source snapshot for the trading terminal UI and backend foundation. Core screens: Dashboard, Market, Commodity, Signals, OI Lab, Watchlist, Search, Charts, Option Chain, News, Market Details, Angel API, NSE, NSE MCP, Data, Instruments, Settings, More.

Floot backend foundations: Postgres database for trade journal, AI memory and market snapshots; Angel One SmartAPI application credential connected server-side; push notifications provisioned.

No Angel MPIN/TOTP/API secret is stored in the database.
